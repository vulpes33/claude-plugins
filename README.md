# claude-plugins

Personal Claude Code plugin catalog.

    /plugin marketplace add rrrfffrrr/claude-plugins

| Plugin | What it is | Install |
|--------|-----------|---------|
| `vulpes` | Wiki mechanics for OKF knowledge bundles - `vwiki` CLI, ruleset, `vulpes:wiki` skill ([repo](https://github.com/rrrfffrrr/vulpes-wiki)) | `/plugin install vulpes@rrrfffrrr` |

Each plugin lives in its own repository (or under `plugins/` here for small ones);
this repository is only the catalog.
